# Hackathon Project: Speech Emotion Recognition

## Description
This project focuses on building a Speech Emotion Recognition (SER) model using Python libraries such as `librosa`, `soundfile`, and `sklearn`. The core tasks include feature extraction from audio files, splitting data into training and testing sets, and training a Multi-Layer Perceptron (MLPClassifier) to recognize emotions from sound. The model's performance is evaluated by calculating its accuracy on the test set.
